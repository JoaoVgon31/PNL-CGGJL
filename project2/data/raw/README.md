# Dados Originais (Raw Data)

Este diretório contém os dados brutos e sem modificações utilizados no Projeto 2:

1. **`cases.csv`**:
   - Amostra oficial de 56 casos clínicos em língua inglesa do corpus MultiCaRe (Nievas Offidani et al., 2025).
   - Colunas: `article_id`, `age`, `case_id`, `case_text`, `gender`.

2. **Gabarito Manual (`data/gold/`)**:
   - 8 casos clínicos anotados manualmente como padrão-ouro para avaliação cega de fronteiras, tipagens semânticas e relações clínicas.
