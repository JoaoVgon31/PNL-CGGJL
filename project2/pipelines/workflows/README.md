# Workflows do Projeto 2

O pipeline do Projeto 2 foi inteiramente implementado de forma programática através de scripts modulares em Python ([`src/`](../../src/)) e demonstrado interativamente via Jupyter Notebooks ([`notebooks/pipeline_projeto2.ipynb`](../notebooks/pipeline_projeto2.ipynb)). 

Dessa forma, não são utilizados fluxos visuais proprietários (como Orange Data Mining), priorizando reprodutibilidade em linha de comando, testes unitários contínuos e portabilidade entre ambientes Linux/macOS/Windows.
